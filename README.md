# UnAnime

UnAnime es una app de Android para ver anime online. Obtiene catálogos, títulos, episodios y streams del sitio fuente y los reproduce en un player integrado con selección de idioma y servidor, pantalla completa, favoritos, galería de capturas del episodio con descarga de imágenes y reproducción en segundo plano.

Reversed from: https://ww4.animeonline.ninja

## Cómo usarlo en Android Studio

Abre el proyecto en Android Studio, espera la sincronización de Gradle y selecciona el build variant `devDebug` en Build > Select Build Variant. Luego ejecuta la configuración `app` en un dispositivo o emulador.

Para compilar por terminal:

```
./gradlew :app:compileDevDebugKotlin
```
