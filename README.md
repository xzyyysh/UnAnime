# UnAnime

UnAnime is an Android app to watch anime online. It scrapes catalogs, titles, episodes and streams from the source site and plays them in a built in player with language and server selection, fullscreen playback, favorites, episode screenshots gallery with image download and background media playback.

Reversed from: https://ww4.animeonline.ninja
